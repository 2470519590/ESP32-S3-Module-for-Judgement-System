# 装甲板固件对接说明

本次 ESP32/L431 比赛通信重构**不要求装甲板修改 CAN 帧格式或自行维护比赛血量**。

装甲板继续执行现有协议：完成自动 NodeID 枚举后，每次确认有效击打向 L431 发对应业务 ID 的 `HIT` 帧（offset `3`，DLC=8）；L431 负责每次扣 `20` HP、死亡、5 秒复活和向 ESP32/服务器上报。装甲板不保存 HP、不决定死亡/复活、不发送 Wi-Fi/UART 比赛帧。

装甲板开发/联调只需保证：

- 一次物理有效击打只入队一次 HIT，不因 CAN 重试或状态查询重复上报；
- HIT 使用当前自动分配 NodeID 对应的业务 ID，而非历史固定 ID；
- CAN 邮箱忙时按现有 FIFO 重试；队列满的行为保持当前定义；
- `0x132` 状态回复、初始化帧和故障帧继续正常，便于 L431 判断节点在线状态；
- 不为 1v1 新增队伍字段或 LED 队伍控制要求。

L431 侧会消费现有 `0x130 + (NodeID - 1) × 0x10 + 3` 命中事件；装甲板无需知晓 ESP32 的 UART1、UDP、ACK 或服务器 IP。
